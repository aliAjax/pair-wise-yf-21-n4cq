# 纹样修复台账 · 手工地毯修复工作室

纯前端的手工地毯纹样修复台账：登记地毯档案、在纹样图上逐个标记破损、配齐补线色与施工说明、留存修复前后记录；标记齐签后方可归档，单个标记可随时重开补修而不影响其他已签标记。不接后台，资料存在浏览器 localStorage，关掉再打开还在。

## 技术栈

React 19 + Vite + TypeScript，无后端、无额外运行时依赖。

## 三份业务文件

| 文件 | 职责 |
| --- | --- |
| `src/model.ts` | 数据模型与存储：地毯 / 破损标记 / 修复前后记录的结构、localStorage 读写、图片压缩、示例台账 |
| `src/rules.ts` | 业务规则（纯函数）：签收校验、重开保留、归档门槛、产地筛选、材料用量汇总、进度指标、CSV 导出 |
| `src/pages.tsx` | 页面组件：页头指标、产地筛选与档案列表、登记表单、纹样标记图、标记检查器、材料用量表 |
| `src/App.tsx` | 装配：状态与所有操作派发，只在上面三层之间接線 |

## 功能对照

- **地毯登记**：产地、年代、结密度（结/平方分米）、材质、染色方式；纹样图可上传（自动压缩），不传则用内置纹样底图。
- **纹样标记**：在图上点击逐个放破损标记（坐标按百分比存储），编号区分待补修（红）/ 已签（青）/ 选中（金）。
- **每个标记一张作业单**：破损类型与位置尺寸、补线色（取色器 + 色名色号 + 用量）、施工说明、修复前/修复后记录（日期、文字、照片）。
- **标记齐了才可归档**：缺项逐项列出（补线色、用量、施工说明、前后记录），全部签收后归档按钮才可用；归档后全档只读。
- **重开补修**：已归档可撤回；已签标记可单独重开，其余已签标记原样保留，重开后须重新签收。
- **产地筛选联动**：筛选后档案列表、顶部四项指标、补线材料用量与进度同步更新。
- **持久化**：所有变更即时写入 localStorage（含照片），刷新或关闭后重开资料仍在；存储超限时页面顶部提示。
- **导出 CSV**：按当前筛选口径导出标记逐行的台账。

首次打开会预置 CAR-092 / CAR-117 / CAR-138 三份示例档案（含已签与待修标记）。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:62009
npm run build    # 类型检查后打包（tsc --noEmit + vite build）
```
