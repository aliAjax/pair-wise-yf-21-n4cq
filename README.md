# 手工地毯修复 · 纹样修复台账

给手工地毯修复工作室使用的纯前端台账，解决纸单上“破损”和“工序”对不上的问题。不接后台，
所有档案存在浏览器 localStorage，关掉再打开资料还在。

## 功能

- **地毯登记**：档案编号、产地、年代、结密度（结/平方英寸、道/英尺等）、材质、染色方式，
  并选择与产地风格对应的纹样底图。
- **纹样图破损标记**：在按产地风格程序化绘制的纹样图（波斯徽章纹 / 安纳托利亚龛形纹 /
  高加索几何纹 / 藏毯方格纹）上点击逐个登记破损，每个编号标记对应一处。
- **标记检查器**：为每处破损配齐部位、破损类型、程度、**补线色**（工作室色卡）、补线用量、
  **施工说明**、**修复前 / 修复后记录**（可附本机压缩照片）。
- **签认与归档规则**：补线色、施工说明、修复前后记录四样齐了才可签认；至少一处破损且
  全部标记签认，整块地毯才可归档。
- **重开补修**：已归档或已签认的某个标记可单独重开，只动这一个标记；其余已签标记保留，
  档案自动撤回归档态，重开原因记入状态轨迹。
- **按产地筛选**：列表、标记数、材料用量（按补线色汇总米数/处数）与进度随筛选同步更新。
- **材料色卡**：内置八种传统植物染色，可随时新增自定义色线。

## 代码组织（三份业务文件）

| 文件 | 职责 |
| --- | --- |
| `src/model.ts` | 数据模型、工厂函数、localStorage 仓储、示例档案 |
| `src/rules.ts` | 归档/签认校验、标记状态流转、产地筛选、材料用量与进度汇总（纯函数） |
| `src/pages.tsx` | 台账列表、档案详情、纹样标记板、标记检查器、色卡、登记弹窗 |

规则层的关键行为由 `scripts/verify-rules.ts` 覆盖（20 条断言）。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62009

## 校验

```bash
npx tsc --noEmit          # 类型检查
npm run build             # 生产构建
node -e "require('esbuild').buildSync({entryPoints:['scripts/verify-rules.ts'],bundle:true,platform:'node',format:'cjs',outfile:'scripts/.verify-rules.cjs'});require('./scripts/.verify-rules.cjs')" && rm scripts/.verify-rules.cjs
```
